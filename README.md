# Stevoo Portfolio

A static site with plain HTML and CSS. No build step is needed.

## Deploy on Vercel
1. Create a new GitHub repository and upload all files in this folder.
2. Go to vercel.com, choose Add New Project and import the repository.
3. Leave the framework preset as Other and the build command empty, then press Deploy.

You can also drag this folder into the Vercel dashboard, or run `npx vercel` inside it.

## Edit
Change text in index.html and colors in the variables at the top of styles.css.
